# Frontend ERP + CRM

Aplicación React y TypeScript organizada por features.

## Desarrollo

```bash
npm run dev
```

## Diseño

Los tokens están en `src/theme/tokens.css`. Cambia `--brand`, `--neutral` y `--radius-base` para ajustar el estilo de toda la aplicación. `--radius-base: 0px` elimina los redondeos. Los colores de éxito, advertencia, error e información son independientes de la marca. Al cambiar `--brand`, comprueba el contraste de `--text-on-brand` con la marca y sus estados.
