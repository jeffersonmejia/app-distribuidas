# OPS-001 — Preparar servicios locales de PostgreSQL y SonarQube

Issue: [#16](https://github.com/jeffersonmejia/app-distribuidas/issues/16) · Responsable: @jeffersonmejia · Área: Calidad

## Objetivo

Definir archivos Compose locales para PostgreSQL del ERP y SonarQube con su propia base PostgreSQL, healthchecks, redes y variables de entorno de ejemplo.

## Instrucciones

1. Revisa el alcance aprobado en la Issue y las referencias del repositorio antes de modificar archivos.
2. Implementa únicamente lo necesario para cumplir los criterios de aceptación de esta tarea.
3. Mantén los cambios dentro de las rutas indicadas y coordina cualquier cambio de alcance antes de ejecutarlo.
4. Actualiza la documentación relacionada y deja evidencia verificable en la Issue o en el entregable correspondiente.

## Criterios de aceptación

- PostgreSQL del ERP se configura con persistencia y healthcheck.
- SonarQube utiliza una base separada y redes aisladas.
- Las credenciales se documentan como variables locales y no se almacenan como secretos reales.

## Dependencias

- Ninguna.
