Inicializar el esqueleto React y TypeScript con Vite y definir tokens globales de identidad, superficies, tipografía, bordes, estados y tema oscuro.

- La aplicación React y TypeScript tiene una estructura inicial ejecutable.
- Los tokens globales están definidos y documentados.
- La base incluye estilos globales y soporte de tema oscuro.
