## Flujo

Usar el SonarQube Community local configurado en `docker/compose.sonarqube.yml` para revisar el código disponible durante el desarrollo. Registrar hallazgos confirmados en `docs/quality-templates/formato_sonar_qube.docx`, exportar PDF breve con captura, descripción, prioridad y responsable, compartirlo por el canal WhatsApp indicado y volver a analizar la corrección.

## Prioridad y seguridad

P0: seguridad, exposición de datos o aislamiento tenant. P1: defectos críticos/altos en flujos principales. P2: defectos relevantes. P3: menores. Usar solo datos sintéticos; no capturar secretos ni datos reales.

## Límite

Es apoyo local y no bloquea PRs ni reemplaza CodeQL/quality-gate. Puede revisar código listo aunque QA-003/004 esperen integración o dependencias.
